# 원기둥을 비스듬히 자르면 — 사인곡선

원기둥을 축과 45° 를 이루는 평면으로 자르고, 잘린 옆면을 높이가 가운데인 곳에서 세로로 잘라 펼치면 잘린 자리가 **사인곡선**이 된다. 이 과정을 보여 주는 수업용 three.js 애니메이션이다. `index.html` 하나로 돌아가고, 설치나 빌드는 필요 없다.

## 수학

반지름 1 인 원기둥 위의 점은 (cos θ, sin θ, z) 이고, 축과 α 의 각을 이루는 평면은 z = x cot α 이다. 둘을 함께 만족하는 잘린 자리의 높이는 다음과 같다.

z = cot α · cos θ

높이가 0 인 θ = −90° 에서 잘라 펼치면, 반지름이 1 이므로 가로 거리 s 는 중심각 θ + 90° 와 같다.

z = cot α · cos(s − 90°) = cot α · sin s

α = 45° 이면 cot α = 1 이므로 z = sin s 이다. 펼친 옆면의 가로 길이는 원기둥의 둘레 2π 이므로 정확히 한 주기가 된다.

## 흐름 (24초, 단계 버튼 1–6 또는 ←/→)

1. 원기둥
2. 45° 평면이 내려와 자른다. 잘린 면은 타원이다.
3. 위쪽 조각을 들어 올려 치운다.
4. 높이가 가운데인 모선(솔기)을 표시한다.
5. 옆면을 편다. 솔기의 한쪽 끝을 붙잡고 곡률을 1 에서 0 으로 줄인다.
6. 좌표축과 y = sin x (분홍 점선)를 겹친다. 높이 재기 점이 곡선 위를 달리며 z 와 sin s 를 견준다.

α 슬라이더(35°–75°)로 각을 바꾸면 진폭이 cot α 로 바뀐다. 주기는 늘 2π 이다.

## 주소 뒤에 붙이는 옵션

| 옵션 | 효과 |
| --- | --- |
| `?t=20&pause` | 20초 자리(펼친 뒤)에서 멈춘다 |
| `&alpha=60` | 평면과 축 사이의 각 |
| `&view=front` | 시점 (`iso`, `front`, `top`) |
| `&sine` | y = sin x 를 늘 겹쳐 보인다 |
